## Objective: Fine-tuned a BERT model to perform Named Entity Recognition (NER) on Bangla text, achieving 98% accuracy.

### Technologies Used: PyTorch, HuggingFace Transformers, BERT, Pandas, NumPy.

### Approach:
- Preprocessed and tokenized Bangla text data using HuggingFace's tokenizers.
- Leveraged PyTorch for training the BERT-based NER model.
- Implemented hyperparameter tuning to optimize model performance.
- Evaluated model accuracy and fine-tuned it to reach 98% precision in identifying entities.

### Results: Successfully developed a robust NER system for the Bangla language, enabling accurate entity recognition from input text.
